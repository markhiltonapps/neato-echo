WHAT CHANGED
------------
1. Cloud-pull mystery (RESOLVED, not a bug): mobile showed no desktop notes because
   the app was signed into mark.hilton@neatoventures.com, not the gmail account that
   holds the 39 migrated notes. Verified via RLS simulation + user/data queries.
   Fix = sign into the same account on both. Added a temporary diagnostic (state vs
   server uid, fetched/added counts) to confirm, then reverted to a clean message.

2. Readable transcripts: desktop meeting transcripts are stored as JSON segment
   arrays and were rendering as raw JSON on mobile. Added packages/core/src/transcript.ts
   (parseTranscriptSegments, resolveSpeakerLabel, groupTranscriptForReading,
   formatTranscriptForReading) — dependency-free, mirrors desktop label precedence.
   Mobile Transcript tab now renders speaker bubbles (You right/teal, others left/cream);
   plain-text phone transcripts keep the editable field. Share exports readable text.
   Tests: test/utils/coreTranscript.test.js (5, all pass).

3. Audio playback for pulled recordings:
   - Mobile: uploads local .wav to echo-audio bucket on push (streamed w/ user token
     so owner=auth.uid()); plays cloud recordings via createSignedUrl stream. "No audio"
     shown when a cloud row has none. Field: cloudAudioPath, persisted.
   - Desktop: new src/helpers/meetingAudioRecorder.js taps dispatchMeetingAudioBuffer,
     streams mic+system PCM to temp files, mixes to userData/meeting-audio/{noteId}.m4a
     via bundled ffmpeg (amix, AAC 64k) at stop. get-meeting-audio IPC + preload.
     neatoCloud.ts uploads it on push and sets audio_path. Duration derived from PCM
     (sidecar {noteId}.json).

4. Duplicate cleanup + sync robustness:
   - Deleted 27 python-migration duplicate rows (id-scheme clash with the app's push).
     Backup table: public.echo_recordings_bak_20260925. Kept app rows (correct local
     times, in the id map). 4 remaining same-name rows are genuinely distinct notes.
   - Mobile pull now RECONCILES (prunes cloud-origin recs no longer in the cloud) and
     REFRESHES metadata on existing cloud recs (durations/renames update in place).
   - Desktop id map moved to userData file (neato-echo-idmap.json) so re-pushes are
     idempotent across reinstalls (prevents future duplication).

5. Desktop auto-push: after a meeting's audio saves, main emits neato-meeting-saved;
   meetingRecordingStore listens and calls pushNotesToCloud (gated by localStorage
   neato.autoPush.v1, default on; toggle in NeatoCloudSettings). No more manual Push.

6. Pull-to-refresh: swipe down on the home list = push + pull (independent try/catch
   so a push hiccup never skips the pull).

7. Folder sync (one-way desktop -> cloud -> mobile): added echo_folders.sort_order;
   neatoCloud.ts upserts folders (id = desktop client_folder_id) and tags each note's
   folder_id. Mobile pulls folders, groups the home list into folder sections in
   desktop sort order (Personal, Meetings, Videos, Ali Zahir, Claude Design, Developers,
   2026 Houston SMB Expo), "On this phone" for unfiled, count badges, newest-first.

8. UI: full-body Neddy mascot on home header, Ask Neddy header, and chat message
   avatars (was head-only). Fixed chat keyboard overlap (KeyboardAvoidingView
   behavior="padding" inside the Modal).
